# bots
LinguaBot: Твой личный репетитор в ВК

Хочешь выучить английский, подтянуть китайский или заговорить на испанском? Забудь о скучных учебниках и дорогих курсах. LinguaBot — это твой персональный помощник для изучения иностранных языков прямо в личных сообщениях ВКонтакте.

📚 Как мы учим?
Мы используем метод погружения и интервального повторения. Бот адаптируется под ваш уровень:
• 🎧 Ежедневные мини-уроки по 5–7 минут (лексика, грамматика).
• 🗣 Распознавание речи для идеальной интонации.
• ✍️ Интерактивные диалоги с ботом-собеседником.
• 💡 Умная система напоминаний (Spaced Repetition) — больше никаких забытых слов.
• 🎮 Геймификация: достижения, уровни и еженедельные челленджи.

⚙️ Что умеет бот?

Подбирает индивидуальную программу обучения.
Проверяет произношение через голосовые сообщения.
Переводит сложные фразы из контекста.
Генерирует упражнения на основе ваших ошибок.
Объясняет правила простым языком без лишней теории.
Собирает вашу личную Anki-колоду внутри диалога.
🆕 Новое в версии 2.0!
Поддержка русского, английского, испанского, китайского и немецкого интерфейсов. Раздел «Словарный запас» теперь синхронизируется между устройствами. Добавлены аудиокарточки от носителей языка.

🎁 Начать очень просто:

Напиши боту /start.
Выбери язык и свой текущий уровень (от A1 до C2).
Получи первое задание уже через 10 секунд!
